# TikTok Accounts API prototype recording

Use this script to record the `Comment` web app for the Accounts API Access Application Form. The recording must show the actual app running. Keep the **بيانات تجريبية** label visible, use only sample data, and add English captions if the narration is in Arabic. Do not describe a simulated action as a completed TikTok API call.

| Time | Screen action | Suggested English narration or captions |
| --- | --- | --- |
| 0–10 s | Open `/demo` and show the Comment inbox and demo-data label. | “This is Comment, a customer engagement web app. This recording shows a prototype with sample data; it is not connected to a live TikTok account.” |
| 10–25 s | Open `/app/integrations`, find TikTok, and open the connection dialog. | “The TikTok account holder will authorize Comment to read comments and replies on their own videos, reply to comments, and hide or unhide unwanted comments. This dialog currently creates a sample account only.” |
| 25–45 s | Complete the sample connection. Click **عرض تعليقات TikTok التجريبية**. | “TikTok comments are filtered into the shared inbox. Our staff can distinguish the source account and review each comment in its video context.” |
| 45–60 s | Open the comment from وليد العمري. Show the related V60 video and the customer's follow-up reply. | “The original video context and comment thread help staff answer accurately.” |
| 60–80 s | Type a sample reply and click **إرسال**. Show the reply in the thread. | “This reply is simulated inside Comment. The prototype does not send it to TikTok.” |
| 80–100 s | Open **إجراءات أخرى**, choose **إخفاء التعليق تجريبيًا**, show the notice, then choose **إظهار التعليق تجريبيًا**. | “Hiding and restoring this comment are also simulations. Live hide and reply calls will require approved Accounts API permissions and the account holder's authorization.” |
| 100–110 s | Return to integrations and show the sample account's disconnect action. | “The live service will revoke access and remove account data when the account is disconnected. This prototype only removes its sample data.” |

Before uploading, watch the entire recording. Confirm that the app name, requested use case, Arabic UI, and English captions are legible, that no private account data appears, and that the simulated nature of connection, reply, and hiding is explicit.
