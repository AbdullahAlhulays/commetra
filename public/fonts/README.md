# Thmanyah Serif Display

The app uses Thmanyah Serif Display for all interface text, Arabic and English.
The five webfont weights are referenced in `src/styles/globals.css` using the
asset URLs served by [Thmanyah's official font site](https://font.thmanyah.com/).
No font binaries are stored in this repository. If those official URLs change,
update the corresponding `@font-face` sources in the stylesheet.

Thmanyah's [font license](https://font.thmanyah.com/licenses) permits use in
websites and apps while restricting independent redistribution of the font
files. Do not add copies to `public/fonts` or publish them separately.
